## 1. Суулгах

| | |
|---|---|
| Android | Play Store-оос **МнКардио** хайж суулгана. Android 7.0-аас дээш |
| iOS | App Store-оос **МнКардио** хайж суулгана. iOS 13-аас дээш |

Анх нээхэд апп мэдэгдэл илгээх зөвшөөрөл асууна. Эм уух, дасгал хийх сануулга ирэхийн тулд
**Зөвшөөрөх**-ийг сонгоно уу.

## 2. Нэвтрэх

Нэг апп дээр эмч, үйлчлүүлэгч хоёулаа нэвтэрнэ.

1. Дээд талаас **Үйлчлүүлэгч** эсвэл **Эмч**-ийг сонгоно.
2. **Нэвтрэх нэр**, **Нууц үг**-ээ оруулна.
   - Үйлчлүүлэгч: эмнэлгээс олгосон нэвтрэх нэр, нууц үг.
   - Эмч: МнКардио вэб системийн нэвтрэх нэр, нууц үг.
3. **Нэвтрэх** товчийг дарна.

Нэвтэрсний дараа эмчийн эсвэл үйлчлүүлэгчийн хэсэг нээгдэхийг таны бүртгэлийн эрх шийднэ.

**Нууц үг 3 удаа буруу оруулбал** анхааруулга гарч, нууц үг сэргээхийг санал болгоно.

### Нууц үгээ мартсан бол

1. Нэвтрэх дэлгэц дээр **Нууц үгээ мартсан уу?** дарна.
2. **Нэвтрэх нэр**-ээ оруулж **Заавар илгээх** дарна. Бүртгэлтэй имэйл рүү сэргээх код ирнэ.
3. **Сэргээх код оруулах** → нэвтрэх нэр, код, шинэ нууц үгээ хоёр удаа оруулна.

Шинэ нууц үг:
- 8-аас доошгүй тэмдэгт
- том латин үсэг (A–Z), жижиг латин үсэг (a–z), тоо, тусгай тэмдэгт (`! @ # $ % _ -` гэх мэт) тус бүр
  нэгээс доошгүй

### Хурууны хээ / нүүр таних

Нэг удаа нууц үгээр нэвтэрсний дараа **Цэс → Тохиргоо → Хурууны хээгээр нэвтрэх**-ийг асаана.
Дараагийн удаа апп нээхэд нууц үгийн оронд хурууны хээ, нүүр таних (Face ID) эсвэл утасны түгжээний
код асууна. Болохгүй бол **Нууц үгээр нэвтрэх** дарна.

## 3. Үйлчлүүлэгчийн хэсэг

Доод цэс: **Нүүр · Тэмдэглэл · Чат · Цэс**.

### Нүүр

Сүүлийн даралт, судасны цохилт, жин, эмчийн хариу, сүүлийн тэмдэглэл, зөвлөгөө нэг дор харагдана.
Доорх хавтангуудаар бүх хэсэг рүү орно: Тэмдэглэл, Асуулт, Цахим үзлэг, Эмчийн зөвлөгөө, ЗСӨ,
Миний бүртгэл, Сэргээн засах.

### 3.1 Миний бүртгэл

Регистр, нэр, төрсөн огноо, утас, хаяг зэрэг эмнэлэгт бүртгэгдсэн мэдээлэл. Буруу байвал эмнэлгийн
бүртгэлд хандаж засуулна.

### 3.2 Миний тэмдэглэл — өдөр тутмын хэмжилт

1. **Тэмдэглэл** цэс → **+** товч → **Шинэ тэмдэглэл**.
2. **Огноо**, **Цаг**, даралт (**Дээд (систол)**, **Доод (диастол)**), **Судасны цохилт**, **Жин**,
   шаардлагатай бол **INR**, тайлбар оруулж хадгална.

Жагсаалтын дээр хугацаа (7, 30, 90 хоног эсвэл өөрөө сонгох) шүүж, графикаар харна. Таныг хяналтад
авсан эмч энэ тэмдэглэлийг харна.

### 3.3 Эмчээс асуух асуулт

**Асуулт** → доод талбарт асуултаа бичээд илгээнэ. Эмчийн хариу мөн энэ урсгалд харагдана.

### 3.4 Эмчийн зөвлөгөө

Эмчийн танд бичсэн зөвлөгөө, тайлбарууд. Зөвхөн унших.

### 3.5 Эрсдэл үнэлгээ (ЗСӨ)

Эмнэлэгт бүртгэгдсэн биеийн хэмжээ, өөрийн өвчний түүх зэрэг эрсдэлийн хүчин зүйлс харагдана.

> Эрсдэлийн оноо, ангилал **харуулахгүй** — тооцох аргачлалыг ЗСҮТ батлах хүртэл дүгнэлтийг эмч гаргана.

### 3.6 Цахим үзлэг

**Цахим үзлэг** → **Хүсэлт илгээх** → зовиур, хүсэлтээ бичээд **Илгээх**. Илгээсэн хүсэлтүүд жагсаалтад
харагдана.

### 3.7 Сэргээн засах, дасгал хөдөлгөөн

Гурван хуудастай:

| Хуудас | Юу хийх |
|---|---|
| **Дасгал хөдөлгөөн** | Дасгалын жагсаалт, заавар, анхааруулга. Дасгал хийснээ тэмдэглэнэ |
| **Амин үзүүлэлт** | Дасгалын өмнө, дараах судасны цохилт, даралт, SpO₂, Боргын үнэлгээ |
| **Үнэлгээ, зөвлөгөө** | Эмчийн эрсдэлийн болон ачааллын үнэлгээ, зөвлөгөө |

> Дасгалын өмнө **анхааруулгыг** заавал уншина уу. Цээжээр өвдөх, амьсгаадах, толгой эргэх бол
> дасгалаа зогсоож эмчдээ хандана.

### Сануулга

**Цэс → Тохиргоо → Сануулга → Сануулга нэмэх**:

1. **Төрөл**: Эм уух · Дасгал хийх · Хяналтын үзлэг · Даралт, жин хэмжих
2. **Гарчиг** (заавал биш) — жишээ нь эмийн нэр
3. **Цаг**
4. **Давтамж** — долоо хоногийн өдрүүдийг (Да–Ня) сонгоно
5. **Хадгалах**

Сануулга утсан дээр ажилладаг тул интернэтгүй үед ч цагтаа ирнэ. Утасны тохиргоонд МнКардиогийн
мэдэгдлийг хаасан бол ирэхгүй.

## 4. Эмчийн хэсэг

Доод цэс: **Нүүр · Үзлэг · Хяналт · Чат · Цэс**.

### Нүүр

- **Эмч хайх** — эмчийн нэр, мэргэжил, байгууллагаар, аймаг/хот, сум/дүүргээр шүүж хайна. Олдсон
  эмчтэй шууд чат эхлүүлнэ.
- **Шинэ тасалбар** — зөвлөгөө хүсэх тасалбар бичих (доор).
- **Сүүлийн 30 хоног** — миний үзлэг, хяналтад буй үйлчлүүлэгч, зөвлөгөөний тоо.
- **Тасалбарууд** — нийтлэгдсэн тасалбаруудын урсгал. Доош гүйлгэхэд цааш ачаална.

### Шинэ тасалбар (зөвлөгөө хүсэх)

1. **Нүүр** → **Шинэ тасалбар**.
2. **Иргэн сонгох** — регистрийн дугаар эсвэл нэрээр тасалбар аль үйлчлүүлэгчийн тухай болохыг сонгоно.
3. Тасалбарын төрлийг сонгоно.
4. Эмнэлзүйн асуулт, зөвлөгөө хүсэх зүйлээ бичиж, шаардлагатай бол зураг, файл хавсаргана.
5. **Нийтлэх** — эсвэл дараа нь үргэлжлүүлэх бол **Ноорогт хадгалах**.

Тасалбарыг нээж сэтгэгдэл, хариу бичиж, файл хавсаргана.

> Нийтэлсэн тасалбар бодит өгөгдөл болж, холбогдох эмч нарт мэдэгдэл очно.

### 4.1 Миний үзлэгүүд

**Үзлэг** цэс. Дээд талд **Миний үзлэг** / **Байгууллагын** гэж сонгоно. Регистр, нэрээр хайж, хугацаагаар
шүүнэ. Үзлэг дээр дарж онош, ICD-10, гомдол зэрэг дэлгэрэнгүйг харна.

### 4.2 Миний хяналт

**Хяналт** цэс → **Хяналтад авах** → үйлчлүүлэгчээ хайж нэмнэ. Жагсаалтад үйлчлүүлэгч бүрийн сүүлийн
хэмжилт харагдана. Дарж тэмдэглэлийн графикийг харна. Хасахдаа үйлчлүүлэгчийн карт дээрх
**Хяналтаас хасах** товчийг дарна.

### 4.3 Миний зөвлөгөө

**Цэс → Хурдан холбоос → Миний зөвлөгөө**. Өөрийн бичсэн тасалбарууд, ноорог.

### 4.4 Миний тайлан

**Цэс → Хурдан холбоос → Миний тайлан**.

1. Хугацаа сонгоно (7, 30, 90, 365 хоног эсвэл өөрөө).
2. Тоон үзүүлэлт, түгээмэл онош, эх сурвалж харагдана.
3. **Тайлан татах** хэсэгт **Excel**, **CSV** эсвэл **Текст** дарна. Хураангуй ба сонгосон хугацааны
   үзлэгүүдтэй файл үүсч, хуваалцах цонх нээгдэнэ — имэйлээр илгээх, Файлууд руу хадгалах, хэвлэх.

Файл бүрт байгууллага, мэдээллийн сан, гаргасан хүн, огноо, хугацаа бичигдэнэ. Утсан дээр нэг удаад
5,000 хүртэлх үзлэг гарна — түүнээс их бол файлд тэмдэглэгдэх бөгөөд бүрэн жагсаалтыг вэбээс гаргана.

### Үйлчлүүлэгчийн карт

**Цэс → Хурдан холбоос → Үйлчлүүлэгч хайх** (3-аас доошгүй тэмдэгт). Картанд:
**Товч** · **Үзлэг** · **Хэмжилт** · **Цахим үзлэг**.

## 5. Чат

**Чат** цэс. Эмчид **Ганцаарчилсан**, **Бүлэг** гэсэн хоёр хуудас.

- **Шинэ яриа** — эмч хайж (нэр, мэргэжил, аймаг, сум) ганцаарчилсан яриа эхлүүлнэ, эсвэл хэд хэдэн
  эмч сонгоод **Бүлэг үүсгэх**.
- Бүлгийн ярианд **Гишүүд** → **Гишүүн нэмэх**.
- **Хавсралт** (📎):

| Сонголт | |
|---|---|
| Зураг авах | Камераар |
| Зургийн сангаас | Утасны зургууд |
| Баримт бичиг | PDF, Word, Excel, текст |
| Дуу бичлэг | Утсан дээр бичсэн бичлэг (Voice Memos, Дуу хураагч) — M4A, MP3, AAC, WAV, OGG |

Нэг файл 50 МБ хүртэл. Ирсэн файл, бичлэг дээр дарж нээнэ, сонсоно.

## 7. Түгээмэл асуулт

**"Сервер дээр алдаа гарлаа" гэж гарвал?**
Интернэт холболтоо шалгаад дахин оролдоно. Давтагдвал хэдэн цагт, аль дэлгэц дээр гарсныг, **Цэс →
Хувилбар**-ын дугаартай хамт дэмжлэгийн хэсэгт мэдэгдэнэ.

**Сануулга ирэхгүй байна.**
Утасны **Тохиргоо → Мэдэгдэл → МнКардио** асаалттай эсэх, батарей хэмнэх горим аппыг хязгаарласан эсэхийг
шалгана.

**Өөр хүний утаснаас нэвтэрсэн.**
Ашиглаж дуусаад **Цэс → Гарах** заавал дарна.
